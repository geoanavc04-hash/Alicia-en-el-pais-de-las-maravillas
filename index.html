EL JARDÍN DE LAS MARAVILLAS

La poción mágica de Alicia

Alicia encontró una botella misteriosa. Ayúdala a descubrir cuánto medirá después de beber la poción y si podrá atravesar la pequeña puerta del jardín.

🧴
La regla mágica

Cada mililitro de poción reduce 2 centímetros de la altura de Alicia.

Altura final = Altura inicial − (Poción × 2)

Altura máxima de la puerta: 100 cm

La cantidad permitida es de 0 a 100 ml.

EL CASTILLO DE CORAZONES

El desafío de la Reina de Corazones

¡Que le corten la cabeza! La Reina quiere que analices una secuencia de cartas numeradas. Clasifica los números pares e impares, calcula sus sumas y descubre qué grupo domina.

👑
Las reglas de la Reina

Los números divisibles entre 2 son pares. Los demás son impares.

Si número % 2 == 0 → par
Si no → impar

Puedes analizar entre 1 y 100 cartas.

Introduce un número entero entre 1 y 100.

La Reina espera tu respuesta...

EL LIBRO DEL CONOCIMIENTO

¿Cómo funciona la magia?

Esta página utiliza HTML para la estructura, CSS para el diseño y JavaScript para procesar los datos. No utiliza bibliotecas ni frameworks externos.

01. La poción mágica

Entrada: altura inicial y cantidad de poción. Proceso: se multiplica la poción por 2 y se resta de la altura inicial. Se utiliza if / else if / else para validar los datos y decidir si Alicia atraviesa la puerta.

Ejemplo: altura 150 cm y poción 30 ml. Altura final: 150 − (30 × 2) = 90 cm. Resultado: Alicia puede pasar.

02. La merienda

Entrada: nombre, bebida y cantidad de tazas. Proceso: switch selecciona el precio unitario; luego se calcula el subtotal. Si se compran 5 tazas o más, se aplica el 10 % de descuento.

Ejemplo: Alicia compra 5 tés de Bs 5. Subtotal: Bs 25. Descuento: Bs 2,50. Total: Bs 22,50.

03. El desafío de la Reina

Entrada: cantidad de cartas. Proceso: un ciclo for recorre los números desde 1 hasta el valor introducido. El operador % identifica los pares y se acumulan las cantidades y las sumas de ambos grupos.

Ejemplo: para 5 cartas, la secuencia es 1, 2, 3, 4, 5. Pares: 2, 4 (suma 6). Impares: 1, 3, 5 (suma 9). Gana el grupo impar.

Conceptos de JavaScript utilizados

  • let: declara variables cuyo valor puede cambiar.
  • const: declara referencias que no se reasignan.
  • if / else: permite tomar decisiones según condiciones.
  • switch: selecciona una opción entre varios casos.
  • for: repite instrucciones un número determinado de veces.
  • function: agrupa instrucciones reutilizables.
  • document.getElementById(): busca un elemento por su identificador.
  • value: obtiene el dato introducido en un campo.
  • textContent: muestra texto dentro de un elemento.
  • addEventListener("submit", ...): detecta el envío de un formulario.
  • preventDefault(): evita que el formulario recargue la página.
  • Number(): convierte un valor en número.
