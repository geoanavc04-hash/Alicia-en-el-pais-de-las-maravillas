# ♠ Alicia en el País de las Maravillas ♥
### Programación Web I

## Descripción
Proyecto web interactivo inspirado en Alicia en el País de las Maravillas.
Desarrollado con HTML5, CSS3 y JavaScript nativo.

## Ejercicios
1. **La poción mágica de Alicia:** cálculo de altura y estructuras condicionales.
2. **La merienda del Sombrerero Loco:** selección de bebidas, cálculo de precios y descuentos con switch.
3. **El desafío de la Reina de Corazones:** clasificación y suma de números pares e impares con for.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Estructura del proyecto
- `index.html`: estructura de la página.
- `css/style.css`: diseño y estilos.
- `js/script.js`: lógica de los ejercicios.
- `evidencias/`: capturas de pantalla.

## Cómo ejecutar el proyecto
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en un navegador.
3. Navega por los tres ejercicios y prueba los formularios.

## Casos de prueba
La página incluye tablas con cinco casos de prueba por ejercicio.
Ejecutar cada caso y completar el resultado obtenido antes de entregar.

## Evidencias
Las capturas de pantalla se encuentran en la carpeta `evidencias/`.
